# ADR-0003：内部研究的数据使用姿态

- 状态：Accepted
- 日期：2026-08-19

IC 当前是反向加载团队的私有内部研究工具。为了让 P0 尽快验证产品价值，我们决定不把逐源重型法律审查设为 tracer bullet 的前置条件；可以低频采集公开可访问内容和团队成员正常获得的订阅内容，在团队内共享标题、摘要、短摘录、回源链接与派生分析。`SourcePolicy` 记录的是系统应执行的采集、处理、保留、展示和删除规则，不等同于“来源已经授权”，本 ADR 也不是法律意见。

最低工程约束仍然生效：不绕过登录、付费墙、CAPTCHA 或其他访问控制，不公开镜像或向团队外再分发正文，凭据与内容隔离，原始/规范全文默认最多保留 7 天，并支持按来源删除 payload 与保留最小 tombstone。系统私有或外部无人知晓不构成风险控制；一旦用途变为公开发布、收费、客户交付、批量再分发、外部 RAG/模型产品或更大范围共享，必须暂停扩展该用途并重新评估来源、权利、隐私和平台限制。
